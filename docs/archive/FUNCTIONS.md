# Funkcije aplikacije (ukratko)

- **Prikupljanje paketa u realnom vremenu** sa npm, PyPI i crates.io.
- **AST analiza koda** (tree-sitter) za više jezika.
- **Detekcija breaking promena** i semantička analiza verzija.
- **Graf zavisnosti**: izgradnja i upiti nad grafom (Memgraph).
- **Vizualizacija grafa** (interaktivni 2D prikaz).
- **Semantička pretraga** paketa pomoću vektorskih embeddinga (Qdrant).
- **Obične pretrage** po nazivu i filtrima (GraphQL API).
- **Impact/Reverse dependents analiza** (radijus uticaja, dependents).
- **Pretplate i live obaveštenja** (WebSocket ažuriranja).
- **API pristup** (GraphQL/REST gateway).
- **Analitika i metrike** (Prometheus/Grafana dashboardi).
- **Monitoring i tracing** (Jaeger/OTel).
- **Bezbednost**: JWT autentikacija, rate limiting, audit log.
- **Autonomni Security Agent** (Gemini 3 funkcije).
- **Skladištenje metapodataka** (PostgreSQL).
- **Streaming pipeline** (Redpanda + RisingWave).
- **Sinhronizacija skladišta** (graph-writer, vector-writer, syncer).
