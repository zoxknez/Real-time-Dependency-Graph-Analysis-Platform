# Gemini 3 Hackathon Checklist

Source: https://gemini3.devpost.com/

## Deadline
- Feb 9, 2026 at 5:00 PM PST

## Submission Requirements
- Text description of Gemini integration (about 200 words).
- Public project link to a working product or interactive demo (no login or paywall).
- Public code repository URL (required if you do not submit an AI Studio app link).
- Demonstration video (about 3 minutes).

## Eligibility and Scope
- Build a new application that uses the Gemini 3 API.
- No category restrictions.

## Judging Criteria
- Technical Execution: 40%
- Innovation / Wow Factor: 30%
- Potential Impact: 20%
- Presentation / Demo: 10%
