# Gemini 3 Hackathon Submission

## Project Title
Autonomous Supply Chain Security Agent

## 200‑Word Gemini Integration Summary
Our application uses Gemini 3 as the autonomous reasoning engine that powers a security agent for software supply chains. The agent orchestrates multi‑step analysis of dependency graphs, automatically deciding which tools to call and in what order. We use Gemini 3 **function calling** to connect the model to real graph data: package search, dependency path tracing, and impact radius analysis. The agent runs in **high thinking level** mode to plan and execute complex workflows and exposes **thought summaries** to explain how each step was chosen. We also use Gemini 3 **structured output** to generate a strict JSON report that includes an executive summary, risk breakdown, top vulnerabilities, and prioritized remediation steps—ready for dashboards and automation. These capabilities transform the product from a chat interface into an autonomous security system that can discover risk, quantify blast radius, and recommend fixes with evidence. The UI visualizes each tool call, shows reasoning summaries, and renders the final structured report for rapid decision‑making. Gemini 3 is central to the product’s uniqueness: without function calling and structured output, it would not be possible to execute or verify these multi‑step security workflows.
