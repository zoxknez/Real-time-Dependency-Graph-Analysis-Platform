# Demo Script (3-5 minutes)

1. Open `/graph` and load a package graph.
2. Select a package and inspect its evidence status and provider attribution.
3. Simulate an API change through the War Room/WebMCP surface and inspect deterministic findings.
4. Calculate direct version exposure; point out exposed, blocked, unknown, and topology counts as separate axes.
5. Assign explicit human priority/exclusion metadata.
6. Inspect real critical paths, generate the bounded migration plan, then focus an available path.
7. Close by showing that Human UI and WebMCP converge through `WarRoomActions`; WebMCP does not bypass application logic.

Do not present unavailable provider data or fixture data as live evidence.
